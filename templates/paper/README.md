# 内置 LaTeX 论文模板（默认骨架）

用途：赛制没有提供官方论文模板时，把本目录复制为工作区的 `paper/`，
作为 LaTeX 默认输出骨架。

本模板按《全国大学生数学建模竞赛论文格式规范（2025年修订稿）》对齐：

- A4，四边页边距至少 2.5 cm；
- 电子版第一页是“摘要专用页”：标题 + 中文摘要 + 关键词，无英文摘要、
  无目录、无作者/学校信息，摘要不超过一页；
- 页码从摘要页起，页脚中部，阿拉伯数字从 1 开始；
- 正文从下一页开始，尽量控制在 20 页以内；
- 参考文献按科技论文规范列在正文后；附录另起一页，包含支撑材料文件列表
  和完整可运行源码；没有程序时写明“本论文没有用到程序”。
- “参考文献”和“附录”使用无编号标题，与常见 Word 版式一致。

复制后：

1. 在 `paper/sections/` 写入 `restatement.tex`、`analysis.tex`、
   `assumptions.tex`、`symbols.tex`、`q1.tex`…`q5.tex`、
   `robustness.tex`、`evaluation.tex`、`appendix.tex`；
2. 在 `paper/refs.bib` 填真实参考文献；
3. 填写标题、中文摘要和关键词；若赛制明确要求英文摘要，取消
   `main.tex` 中注释掉的英文摘要块；
4. 编译：`xelatex main && bibtex main && xelatex main && xelatex main`。

规则：

- 若赛制提供官方模板，必须优先使用官方模板，本文件仅作无官方模板时的默认骨架；
- 没有官方模板时，直接用本模板出 LaTeX，不停下等模板，也不默认回退 Markdown；
- 全文匿名，任何地方不得出现姓名、学校、赛区信息；
- 符号表使用 `longtable`，与 `planning/symbol_table.md` 保持一致；
- 不要目录（官方规范明确“不要目录”）；
- 代码只出现在附录，正文禁止代码块；
- 参考文献必须真实，禁止编造。
